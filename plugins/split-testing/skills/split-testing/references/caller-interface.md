# Caller Interface

Load this route only when comparative evidence crosses a versioned caller boundary. The interface transfers a live claim, authority, closure conditions, effect boundaries, and evidence references without prescribing how observations are arranged or replacing the native evidence basis.

`comparative-evidence-request.v1` is defined by [the request schema](../schemas/comparative-evidence-request.v1.schema.json). Preserve the exact frozen UTF-8 request bytes because the result digest binds those bytes rather than parsed or reformatted JSON. Preserve unknown fields byte-for-byte in retained custody and semantically across any authorized transformation. A request must not prescribe observations, dimensions, cases, graders, scores, topology, output form, or familiar instrument lineage as caller-chosen comparison design. Do not misclassify a rightful authority requirement, adopted standard, real deployment or consumer boundary, prohibited effect, or caller-owned closure condition as design prescription; carry it through `authority_ref`, `decision_context`, the applicable boundary field, or an extension, and honor it to the extent of its authority.

Each closure condition carries an `id` that is stable and unique within the request plus a caller-authored `statement`. It says what evidence would close, narrow, or leave the caller's claim unresolved; it does not choose the comparison design. `prohibited_effects` bounds evidence, disclosures, costs, or external actions the comparison is not authorized to create.

`comparative-evidence-result.v1` is defined by [the result schema](../schemas/comparative-evidence-result.v1.schema.json). Preserve the original `claim_id`, calculate `request_digest` as lowercase SHA-256 over the exact frozen request bytes, identify the actual tested conditions, reference the native evidence basis, and assess every requested closure-condition ID exactly once as `closes`, `narrows`, or `does_not_resolve` without adding an unrequested ID. Those statuses belong only to this exchange interface and are not a universal result vocabulary.

Keep `conclusion`, `scope_and_limits`, `uncertainty`, and `reopening_conditions` open to the live evidence. Modality-specific cases, attempts, assignments, resources, source snapshots, executable states, human responses, and other details remain in referenced native evidence only when applicable. The result bears on the supplied claim; the caller retains authority over the action or disposition that follows.
