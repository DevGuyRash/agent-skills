# Task-value Evidence

Use this reference only when the audit decision still depends on whether the target changes task
behavior. A deterministic defect can decide release without making behavioral value unknowable; it
can also make a costly comparison irrelevant to the current direction.

Use `$split-testing` when available, equivalent fresh host sessions otherwise, and leave the claim
unverified when isolation is unavailable. The comparison must observe the target's intended
contribution at the layer where that contribution exists. Artifact reviewers do not substitute for
users, operators, deployed hosts, or task executors, and a source-incomplete checker does not
establish end-to-end correctness. Treatment executors receive the target while controls do not;
required dependencies, model, authority, task inputs, and collection boundary remain common. Confirm
target loading, preserve every attempt, and keep each plugin skill's conclusion distinct.

When the host can auto-discover another installed or cached skill with the same identity or purpose,
a prompt-assigned source path is not exposure proof. Isolate the competing copy or retain host trace
and source identity showing which instructions were actually loaded. Retired output forms, rules, or
tool behavior from another version contaminate the condition even when the executor was told not to
use them; exclude an ambiguous or mixed-source run rather than attributing it to the candidate.

Treat the deployed input to each agent as the actual condition. Shared prompt material that states a
desired answer, repeats treatment logic, reveals a suspected defect, or supplies evaluator-only facts
can erase or replace the contrast even when condition labels differ. Prompt purity is a causal
property of the composed payload, not of a prompt template inspected before launch.

Treat the evaluation system as fallible target evidence. A researched or generated rubric does not
acquire maker authority: its criteria, scales, weights, gates, and required forms must measure the
user's outcome and remain able to represent an unanticipated material issue. Plausible post-hoc prose
does not validate an invented weight, threshold, tie band, or worksheet. Look for maker-fixed
tradeoffs, empirical calibration, a formal consequence model, a consumer interface, or behavioral
evidence at the strength claimed.

A private oracle, reference answer, checker, or earlier validation remains contradictable
measurement evidence. Before candidate exposure, independent validation must be able to correct or
extend it from stronger target authority. After exposure, changing the instrument creates a new
prospective comparison; it does not silently repair the old evidence. Blinding and reviewer agreement
reduce selected biases without establishing truth, criterion validity, representative use, or
source-faithful checking.

Inspect the authority boundary of instrument construction. A rubric author or validator may be
correctly governed by ambient repository or host instructions that the measured executors and
reviewers never receive; those instructions do not become target criteria unless the deployed stack
adopts them. Independence cannot repair an authority mismatch and can make the imported rule look
more credible when the exact deployed input stack is not preserved.

Replication must re-expose the uncertainty named by the claim. Fresh executors can measure executor
variation; identical deterministic reruns inside one executor establish consistency, not independent
agent variation. Every review layer needs a distinct unresolved property. A nested panel that
re-scores a trusted oracle, repairs its own evaluator-authored summary, or duplicates the outer review
adds self-generated process cost rather than independent task evidence.

Keep option evidence, artifact quality, and decision authority distinct. A reviewer may establish
that a report omitted an available fact; that rescue belongs to the condition containing the review
and does not add evidence about the options or prove the omission's earlier cause was fixed. Consensus
cannot choose unresolved utility, risk, taste, or acceptance for an absent maker unless that reviewer
population is the decision role under test. Once adopted deterministic evidence fixes the factual
frontier and only rightful preference remains, more agents observe no decision-changing target
property.

Compare outcomes at a shared consequence boundary. Equal totals or averages can conceal unequal
distributions, interactions, tails, or case profiles. Two true quantities from different cases,
populations, deadlines, scales, or loss meanings do not establish a benefit without an adopted
normalization. Judge semantic correctness and material task value before cost, then attribute all
review, repair, and execution cost to the condition that incurred it.

The conclusion must state what the comparison actually isolates, where it applies, and what could
reopen it. A preference alone does not prove correctness, causality, generalization, or a foundational
repair.
